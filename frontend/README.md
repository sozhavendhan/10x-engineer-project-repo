# PromptLab Frontend

This is the React/Vite frontend for PromptLab. It connects to the FastAPI backend and provides a simple interface for managing prompts and collections.

## Features

- View all prompts
- Create new prompts
- Edit existing prompts
- Delete prompts
- Assign prompts to collections
- Create collections
- View collection list
- Add comma-separated tags to prompts
- Connect to FastAPI backend using environment configuration

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- FastAPI backend integration
